# Desktop Client — Moved

The end-user desktop client for WaddleBot (Waddles Bridge) has been consolidated into the
**Penguin Desktop Client** as a plugin module.

**New location:** https://github.com/penguintechinc/penguin
- Module source: `services/desktop/internal/modules/waddlebot/`
- Plugin binary: `penguin-mod-waddlebot`

The core services (Premium/Mobile, core, config, action, trigger, sdk, etc.) remain in this repository.
